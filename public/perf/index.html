Less code on every page

NordPass loads this code into every page and every embedded frame before it can do anything. Less code means less for the browser to read on each page load, less memory, and shorter freezes. Form recognition is half the size because its TensorFlow engine was replaced with a lightweight custom one, and drawing the icon was moved out of it.

Conclusion
    Possible next steps
    • Load the autofill pop-up code only when a pop-up is about to show, instead of on every page. This is the biggest remaining win.
    • Set up form recognition only where the page has a form to fill.
